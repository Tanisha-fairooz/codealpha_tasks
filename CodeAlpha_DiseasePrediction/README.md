This project uses machine learning to classify breast tumors as benign or malignant using the UCI Breast Cancer Wisconsin (Original) dataset (699 samples, 9 features). Data is cleaned, missing values imputed, and features scaled before training three classifiers — Logistic Regression, Random Forest, and SVM — which are evaluated on accuracy, precision, recall, and F1 score. The SVM model performed best, achieving ~95.7% accuracy. Built with Python, pandas, scikit-learn, and matplotlib; for educational purposes only, not for clinical use.
